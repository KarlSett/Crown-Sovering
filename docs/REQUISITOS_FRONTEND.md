# Requisitos y pantallas de frontend (RF-01 a RF-66 · RNF-01 a RNF-33)

Fuente: `REQUERIMIENTOS_FUNCIONALES_corregido.docx`. Este mapa distingue representación visual de ejecución real en el frontend nativo WPF (`.NET Framework 4.7.2`). Los listados usan datos sintéticos y las operaciones producen borradores revisables sin persistencia remota.

## Requerimientos No Funcionales (`RNF-01` a `RNF-33`) y Alcance

- **Arquitectura y conexión (`RNF-01`–`RNF-03`)**: Aplicación nativa de escritorio Windows en WPF (`RNF-01`), indicador de conexión cloud y modo de bloqueo preventivo de operaciones críticas sin pérdida de datos en formulario ante caída de red (`RNF-02`).
- **Seguridad y roles (`RNF-08`–`RNF-14`, `RF-66`)**: Acceso exclusivo para personal autorizado con 3 roles de demostración (`Administrador`, `Gerente`, `Recepcionista`), separación estricta entre gestión administrativa (sin Reservas) y recepción operativa, flujos de bloqueo/desbloqueo, cierre remoto de sesión e inmutabilidad visual de auditoría.
- **Usabilidad, accesibilidad y temas (`RNF-21`–`RNF-25`)**: Flujos guiados paso a paso con validación en tiempo real (`RNF-21`), inputs con hints aislados que jamás se superponen al texto, tres temas (`Claro`, `Oscuro`, `Marca` en escala esmeralda `#EBFEF7`–`#004D40`–`#003029`), atajos de teclado (`Alt+T`, `Ctrl+Shift+↑/↓`, `Ctrl+F`, `F1`, `Esc`) y soporte de plantillas ES/EN (`RNF-25`).
- **Supuestos de alcance respetados**: Canales de reserva registrados manualmente sin integración OTA externa y moneda principal única sin multimoneda ni tipo de cambio.
