# Vídeo opcional del login

La presentación funciona ahora con hospitality-lobby.png, una imagen local animada suavemente, con control de pausa.

Para usar vídeo, colocar aquí un archivo propio o con licencia llamado hospitality.mp4 (H.264, preferiblemente sin audio, 720p o 1080p, movimiento lento). Volver a compilar: el proyecto lo copia a la misma ruta dentro de bin/Debug o bin/Release. No hace falta cambiar el XAML.

La vista reproduce el archivo local en bucle y silencio. El control de pausa actúa sobre el vídeo; la fotografía cubre la carga y los errores. No se hacen descargas desde el login.

No se ha incluido un MP4 porque el entorno bloqueó las descargas de red. Una posible fuente revisada es White luxury boutique hotel room de Mixkit, que indica licencia gratuita para uso comercial o personal: https://mixkit.co/free-stock-video/white-luxury-boutique-hotel-room-4046/ . Revisar la licencia del clip concreto al descargarlo.
